# اپلیکیشن اندروید رونی‌ماف

اپ، محتوا را مستقیم از REST API وردپرس سایت (`https://runimaf.org/wp-json/wp/v2/`) می‌خواند؛
پس هر نوشته یا پادکست/فیلمی که روی سایت منتشر شود، بدون هیچ کار اضافه‌ای در اپ هم دیده می‌شود.

## اجرا
1. Android Studio (نسخه‌ی جدید) را نصب کنید و پوشه‌ی پروژه را باز کنید (File ▸ Open).
2. صبر کنید Gradle همگام‌سازی شود (نیاز به اینترنت).
3. گوشی یا شبیه‌ساز را وصل کنید و Run را بزنید.

## ساخت فایل APK برای سایت
Build ▸ Generate Signed App Bundle / APK ▸ APK ▸ یک Keystore بسازید (و آن را با رمز، جای امن نگه دارید؛
بدون آن نمی‌توانید به‌روزرسانی منتشر کنید). فایل خروجی را در سایت آپلود کنید.

## تنظیمات مهم
- `Api.kt`: آدرس سایت، آدرس لوگو و «نامک زبان‌ها» در Polylang (کوردی: `ckb` یا `ku`).
- `Strings.kt`: متن‌های اپ به سه زبان.
- نیاز دارد قالب رونی‌ماف نسخه‌ی ۴٫۲ یا بالاتر روی سایت فعال باشد (فیلد `media_url` در REST API).
